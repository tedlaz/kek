# KEK ΚΑΔ->Ειδικότητα->ΚΠΚ

Μικρή standalone web εφαρμογή για αναζήτηση ΚΑΔ/Ειδικότητας και εύρεση ΚΠΚ από τοπικά αρχεία δεδομένων.

[Live demo](https://tedlaz.github.io/kek)

## Τι κάνει

- Αναζήτηση **ΚΑΔ** με κωδικό ή περιγραφή.
- Επιλογή ΚΑΔ και εμφάνιση **φιλτραρισμένης λίστας Ειδικοτήτων** από το `kad_eid_kpk.txt`.
- Επιλογή ΕΙΔ και εμφάνιση αντίστοιχου **ΚΠΚ**.
- Εμπλουτισμός αποτελέσματος από `kpk.txt` (περιγραφή + ποσοστά + ημερομηνία έναρξης).

## Αρχεία δεδομένων

Στον ίδιο φάκελο με το `index.html`:

1. `kad.txt` (στήλες: `kad;per`)
2. `eid.txt` (στήλες: `eid;per`)
3. `kad_eid_kpk.txt` (στήλες: `kad;eid;kpk;ymfrom;ymto`)
4. `kpk.txt` (στήλες: `kpk;per;pemployee;pcompany;ptotal;dfrom`)

Όλα είναι `;`-separated με header στην πρώτη γραμμή.

## Τρόποι εκτέλεσης

### 1) Server mode (προτεινόμενο)

Παράδειγμα:

```bash
cd /home/ted/prj/kek
python3 -m http.server 8080
```

Άνοιξε: `http://localhost:8080`

Συμπεριφορά:
- Γίνεται **auto-load** των 4 αρχείων από τον ίδιο φάκελο.
- Το `filePickerRow` κρύβεται αυτόματα.

### 2) File mode (`file://`)

Άνοιξε το `index.html` απευθείας.

Συμπεριφορά:
- Εμφανίζεται επιλογή φακέλου.
- Πατάς **«Φόρτωση από φάκελο»** και η εφαρμογή χαρτογραφεί αυτόματα τα 4 αρχεία με βάση το όνομα.

## UX behavior

- Οι λίστες είναι ταξινομημένες αριθμητικά:
  - ΚΑΔ list by `kad`
  - ΕΙΔ list by `eid`
- Αν στο filtering μείνει **1 μόνο αποτέλεσμα**, γίνεται auto-select:
  - για ΚΑΔ
  - για ΕΙΔ
- Κατά την πληκτρολόγηση:
  - στο ΚΑΔ input καθαρίζονται τα lower-level δεδομένα (ΕΙΔ/KPK)
  - στο ΕΙΔ input καθαρίζεται το KPK result
- Στο KPK result υπάρχει εναλλασσόμενο χρώμα γραμμών (zebra, έντονο).
- Αν δεν βρεθεί αντιστοίχιση στο `kpk.txt`, εμφανίζεται μήνυμα με κόκκινο χρώμα.

## Τεχνολογία

- Καθαρό HTML/CSS/Vanilla JS
- Χωρίς backend dependency για βασική λειτουργία

## Δομή project

- `index.html` — UI
- `styles.css` — εμφάνιση
- `app.js` — parsing, loading, searching, selection flow
- `*.txt` — δεδομένα

## Σημειώσεις

- Οι τιμές `pemployee`, `pcompany`, `ptotal` διαβάζονται όπως είναι στο `kpk.txt` (ελληνική μορφή δεκαδικών με κόμμα).
- Η `dfrom` εμφανίζεται όπως δίνεται στο αρχείο.
